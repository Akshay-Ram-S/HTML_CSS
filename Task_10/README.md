## Interactive Multi-Page Website Simulator with CSS Only

## Objective

To create a fully functional, multi-section website that simulates the experience of navigating between different pages

## Concepts used

1. :target Pseudoclass - To display and hide different “pages” or sections of content.
   <br>
2. CSS transitions - To simulate page transitions
   <br>
3. Flexbox - Used in navigation bar
   <br>
4. Grid - Used in services
   <br>
5. Margin and Padding - Used to set margin and padding for elements.

## Website Description

The website contains 4 sections -

1. Home
   <br>
2. About us
   <br>
3. Services
   <br>
4. Contact
   <br>

We can navigate between any sections of the page using navbar. All the sections of the website are set in a single page and we use :target pseudoclass to make a particular section visible.
